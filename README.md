# LensLoop

LensLoop is a modern, responsive web application that lets users search and explore dynamic image collections cleanly and efficiently.

## App Overview
This application serves as a media search portal where users can search for specific image topics or choose from popular category chips to view a wall of responsive image results.

## Design Decisions
1. **Emerald Dark Theme:** I chose a slate/emerald color palette to provide a sleek, high-contrast viewing experience that differs from standard light themes and highlights visual content effectively.
2. **Category Suggestions Row:** I added clickable suggestion chips (e.g., Nature, Architecture, Cyberpunk) below the main search bar to allow users to quickly search popular subjects with a single click.
